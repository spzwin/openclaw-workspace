## 模块B — 内部渠道数据（CLI查询）

**来源类型**: `CLI查询`

**目标变量**: `{internal_query_id_or_result}`（渠道表各行"内部数据依据"列）, `{representative_hospitals}`

**CLI命令**（串行执行）:

```bash
# B-01：按医院级别大类分组（填充三级/二级/一级各层覆盖情况）
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-2.2-B01-level-group" \
  --query-output-dir "省份报告/{province}/2.2_省级治疗渠道分布/搜索结果/B_内部渠道数据" \
  group --by 医院级别大类 --sort-by total_potential --desc --省 "{province}"

# B-02：按类型名称分组（综合/专科/基层医疗的分布）
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-2.2-B02-type-group" \
  --query-output-dir "省份报告/{province}/2.2_省级治疗渠道分布/搜索结果/B_内部渠道数据" \
  group --by 类型名称 --sort-by total_potential --desc --省 "{province}"

# B-03：双品产品对比（填充各渠道层产品覆盖率）
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-2.2-B03-product-compare" \
  --query-output-dir "省份报告/{province}/2.2_省级治疗渠道分布/搜索结果/B_内部渠道数据" \
  product-compare --省 "{province}"
```

**说明**:
- B-01 `group --by 医院级别大类` 输出三级/二级/一级各层的医院数、IDA患者数、莫诺菲流向、科莫非流向、覆盖率，直接填入渠道表的 `{internal_query_id_or_result}` 列
- B-02 补充综合/专科/基层三类渠道分布
- B-03 双品覆盖率数据支撑渠道优先级判断

---

## 数据获取优先级约定

1. **第一优先** — CLI 内部数据（渠道层级覆盖数据）→ 填 `{internal_query_id_or_result}`
2. **第二优先** — {省份}卫健委医院分级分类公开数据
3. **第三优先** — 分级诊疗政策文件和医药行业报告
4. **兜底** — 无内部数据时用"待内部数据补充"
