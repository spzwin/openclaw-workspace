## 模块D — 内部普外科/骨科数据（CLI查询）

**来源类型**: `CLI查询`

**目标变量**: `{internal_data}`（本省重点外科/骨科"内部IDA患者数/流向"列）

**CLI命令**（串行执行）:

```bash
# D-01：按IDA患者数排名Top20
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-6.3-D01-top-hospitals" \
  --query-output-dir "省份报告/{province}/6.3_普外科骨科/搜索结果/D_内部外科数据" \
  rank --by 客户名称 --metric IDA患者数 --top 20 --省 "{province}"

# D-02：莫诺菲已覆盖医院明细
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-6.3-D02-monof-covered" \
  --query-output-dir "省份报告/{province}/6.3_普外科骨科/搜索结果/D_内部外科数据" \
  detail --省 "{province}" --产品 "莫诺菲" --flow-status covered --sort-by IDA患者数 --desc --top 20
```

## 数据获取优先级约定

1. **第一优先** — CLI 内部数据（填 `{internal_data}`）
2. **第二优先** — {省份}医学会外科/骨科/麻醉科分会（KOL、PBM 实践）
3. **第三优先** — 中国 PBM 专家共识、NATA 指南（患者池背景）
4. **兜底** — 无省级数据时填"估算：全国手术量×{省份}比例×围术期贫血率"
