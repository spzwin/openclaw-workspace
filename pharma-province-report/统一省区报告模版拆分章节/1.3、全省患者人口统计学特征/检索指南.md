## 模块09 — 输出报告填充规则

**来源类型**: `联网搜索`

| 报告字段 | 数据来源优先级 | 填充说明 |
|---|---|---|
| `{national_age_pattern}` | GBD 2023 > 中华儿科杂志 > 流调文献 | 描述全国年龄分布规律及关键数据 |
| `{province_age_pattern}` | 省份特异性流调 > 省级医院数据 > 推断自全国数据 | 若无省份数据，注明"参考全国数据分布" |
| `{national_gender_pattern}` | GBD 2023 > 中国专家共识 | 描述性别差异及育龄女性高危原因 |
| `{province_gender_pattern}` | 省份特异性数据 > 推断自全国数据 | 若无省份数据，注明"参考全国数据" |
| `{national_urban_rural_pattern}` | 国家卫生服务调查 > GBD 2023 SDI分析 | 描述SDI与患病率负相关性 |
| `{province_urban_rural_pattern}` | 省份卫健委数据 > 卫生年鉴 > 推断自全国数据 | 省内珠三角/沿海vs山区农村差异 |
| `{national_comorbidity_pattern}` | GBD 2023病因分析 > 中国专家共识 > 亚洲指南 | 按病因排序：膳食铁缺乏主因，合并CKD/心衰/IBD/妊娠等 |
| `{province_comorbidity_pattern}` | 省份医院数据 > 全国数据推断 | 结合省份特点（如地贫高发区需鉴别诊断） |
| `{source_or_method}` | 文献PMID > 官方数据库 > 推断说明 | 标注数据来源，若为推断需注明 |
