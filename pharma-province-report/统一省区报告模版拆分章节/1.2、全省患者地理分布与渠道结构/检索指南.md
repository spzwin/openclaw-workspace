## 模块G — 产品流向与渠道结构（内部数据，CLI查询）

**来源类型**: `CLI查询`

**目标变量**: `{internal_query_id_or_result}`, `{concentration_level}`, `{market_potential}`（城市分层表"内部数据依据"列）, `{healthcare_supply_summary}` 中的覆盖率部分

**CLI命令**（串行执行）:

```bash
# G-01：省级总览（填充整体医院数/IDA患者数/覆盖情况）
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-1.2-G01-summary" \
  --query-output-dir "省份报告/{province}/1.2_全省患者地理分布与渠道结构/搜索结果/G_产品流向与渠道结构" \
  summary --省 "{province}"

# G-02：城市维度分组（填充城市分层表各行的"内部数据依据"列）
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-1.2-G02-city-group" \
  --query-output-dir "省份报告/{province}/1.2_全省患者地理分布与渠道结构/搜索结果/G_产品流向与渠道结构" \
  group --by 市 --sort-by total_potential --desc --省 "{province}"

# G-03：产品双品对比（填充渠道结构描述和覆盖率）
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-1.2-G03-product-compare" \
  --query-output-dir "省份报告/{province}/1.2_全省患者地理分布与渠道结构/搜索结果/G_产品流向与渠道结构" \
  product-compare --省 "{province}"

# G-04：医院级别大类分组（填充渠道层级表各行的"内部数据依据"列）
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-1.2-G04-level-group" \
  --query-output-dir "省份报告/{province}/1.2_全省患者地理分布与渠道结构/搜索结果/G_产品流向与渠道结构" \
  group --by 医院级别大类 --sort-by total_potential --desc --省 "{province}"
```

**说明**:
- G-01 `summary` 提供全省医院总数、IDA患者数、两产品整体覆盖率
- G-02 `group --by 市` 按城市拆解 IDA患者数 / 莫诺菲流向 / 科莫非流向，支撑城市分层表"内部数据依据"列
- G-03 `product-compare` 输出双品覆盖医院数、双覆盖/单覆盖/零覆盖分布
- G-04 `group --by 医院级别大类` 输出三级/二级/一级医院各层的流向数据，支撑渠道结构表

## 数据获取优先级约定

1. **第一优先** — CLI 查询内部数据（IDA患者数、产品流向、覆盖率）→ 填入 `{internal_query_id_or_result}` 字段
2. **第二优先** — {省份}卫健委官网最新「医疗卫生资源和医疗服务情况简报」
3. **第三优先** — 国家卫健委 / 国家统计局官方数据
4. **第四优先** — 权威医学期刊、学会指南、专家共识
5. **兜底** — 基于一般知识估算，标注"估算"，注明待内部数据精校
