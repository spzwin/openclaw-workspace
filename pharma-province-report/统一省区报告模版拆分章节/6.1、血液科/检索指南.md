## 模块D — 内部血液科数据（CLI查询）

**来源类型**: `CLI查询`

**目标变量**: `{internal_data}`（本省重点医院血液科表"内部IDA患者数/流向"列）

**CLI命令**（串行执行）:

```bash
# D-01：血液科相关医院的莫诺菲流向覆盖情况（Top20）
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-6.1-D01-top-hospitals" \
  --query-output-dir "省份报告/{province}/6.1_血液科/搜索结果/D_内部血液科数据" \
  rank --by 客户名称 --metric IDA患者数 --top 20 --省 "{province}"

# D-02：莫诺菲已覆盖医院明细
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-6.1-D02-monof-covered" \
  --query-output-dir "省份报告/{province}/6.1_血液科/搜索结果/D_内部血液科数据" \
  detail --省 "{province}" --产品 "莫诺菲" --flow-status covered --sort-by IDA患者数 --desc --top 20
```

**说明**:
- D-01 `rank` 提供各医院 IDA患者数和双品流向，填入 `{internal_data}` 列
- 血液科内部数据按医院级别筛选三甲医院，非销量核心科室，重在 KOL 定位

---

## 数据获取优先级约定

1. **第一优先** — CLI 内部数据（各医院 IDA患者数 / 流向，填 `{internal_data}`）
2. **第二优先** — {省份}医学会血液学分会（KOL 信息）
3. **第三优先** — 医院官网（科室介绍、专家简介）
4. **第四优先** — PubMed / CNKI 流行病学文献（患者池估算）
5. **兜底** — 无省级数据时填"估算：基于全国比例"
