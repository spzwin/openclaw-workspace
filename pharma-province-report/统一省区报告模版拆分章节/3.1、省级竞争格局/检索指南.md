## 模块C — 内部产品流向数据（CLI查询）

**来源类型**: `CLI查询`

**目标变量**: `{product_b_access_status}`, `{product_a_access_status}` 中的流向部分（内部销售状态）

**CLI命令**（串行执行）:

```bash
# C-01：双品产品对比（我方两品覆盖率、流向对比）
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-3.1-C01-product-compare" \
  --query-output-dir "省份报告/{province}/3.1_省级竞争格局/搜索结果/C_内部流向数据" \
  product-compare --省 "{province}"

# C-02：省级总览（确认内部整体覆盖现状）
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-3.1-C02-summary" \
  --query-output-dir "省份报告/{province}/3.1_省级竞争格局/搜索结果/C_内部流向数据" \
  summary --省 "{province}"
```

**说明**:
- C-01 `product-compare` 提供两款产品的覆盖医院数、覆盖率、双覆盖/单覆盖/零覆盖分布，填入 `{product_b_access_status}` 和 `{product_a_access_status}` 的"流向状态"部分
- 竞品（蔗糖铁等）流向状态通过联网搜索获取公开信息，注明"公开渠道信息"

---

## 数据获取优先级约定

1. **第一优先** — 产品资料（references/）+ CLI内部数据 → 我方产品准入/流向状态
2. **第二优先** — {省份}集采平台、医保局 → 我方和竞品挂网状态
3. **第三优先** — 医药行业报告（米内网、IMS Health公开数据）→ 竞品市场格局
4. **兜底** — 竞品流向无内部数据时注明"竞品内部流向数据不可用，建议市场部补充"
