## 模块C — 内部医院结构数据（CLI查询）

**来源类型**: `CLI查询`

**目标变量**: 内部医院数（与公开数据交叉验证）, 各层级产品覆盖情况（支撑 `{product_implication}` 分析）

**CLI命令**（串行执行）:

```bash
# C-01：按医院级别大类分组（内部视角的医院层级分布）
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-5.1-C01-level-group" \
  --query-output-dir "省份报告/{province}/5.1_省级医疗体系概览/搜索结果/C_内部结构数据" \
  group --by 医院级别大类 --sort-by total_potential --desc --省 "{province}"

# C-02：按城市分组（各城市医院分布和IDA患者集中度）
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-5.1-C02-city-group" \
  --query-output-dir "省份报告/{province}/5.1_省级医疗体系概览/搜索结果/C_内部结构数据" \
  group --by 市 --sort-by total_potential --desc --省 "{province}"

# C-03：省级总览
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-5.1-C03-summary" \
  --query-output-dir "省份报告/{province}/5.1_省级医疗体系概览/搜索结果/C_内部结构数据" \
  summary --省 "{province}"
```

**说明**:
- C-01/C-02 提供内部视角的医院层级分布和城市分布，与公开卫健委数据交叉验证，支撑 `{product_implication}` 判断
- C-03 提供内部库中{省份}医院总数（注意：内部库不等于全省医院总数，需注明口径差异）

## 数据获取优先级约定

1. **第一优先** — {省份}卫健委官网最新「医疗卫生资源和医疗服务情况简报」
2. **第二优先** — CLI 内部数据（内部视角医院结构，需注明"内部库口径"）
3. **第三优先** — 国家卫健委统计数据、卫生统计年鉴
4. **兜底** — 无省级数据时填"暂无最新数据，建议查阅{省份}卫健委官网"
