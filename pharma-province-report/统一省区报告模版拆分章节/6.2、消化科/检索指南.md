## 模块D — 内部消化科数据（CLI查询）

**来源类型**: `CLI查询`

**目标变量**: `{internal_data}`（本省重点医院消化科"内部IDA患者数/流向"列）

**CLI命令**（串行执行）:

```bash
# D-01：按IDA患者数排名Top20（覆盖消化科主要医院）
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-6.2-D01-top-hospitals" \
  --query-output-dir "省份报告/{province}/6.2_消化科/搜索结果/D_内部消化科数据" \
  rank --by 客户名称 --metric IDA患者数 --top 20 --省 "{province}"

# D-02：莫诺菲已覆盖医院（消化科重点追踪）
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-6.2-D02-monof-covered" \
  --query-output-dir "省份报告/{province}/6.2_消化科/搜索结果/D_内部消化科数据" \
  detail --省 "{province}" --产品 "莫诺菲" --flow-status covered --sort-by IDA患者数 --desc --top 20
```

## 数据获取优先级约定

1. **第一优先** — CLI 内部数据（医院流向，填 `{internal_data}`）
2. **第二优先** — {省份}医学会消化学分会 / ECCO中国区（KOL）
3. **第三优先** — PubMed / CNKI（IBD、消化道出血流行病学）
4. **兜底** — 无省级数据时填"估算：全国比例×{省份}人口"
