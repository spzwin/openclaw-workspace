## 模块B — 内部医院数据（CLI查询）

**来源类型**: `CLI查询`

**目标变量**: `{internal_data_summary}`（重点医院表"内部IDA患者数/流向"列）, `{priority_city_or_hospital_cluster}`, `{coverage_strategy_summary}`

**CLI命令**（串行执行）:

```bash
# B-01：按IDA患者数排名Top20医院（确定重点医院名单和潜力值）
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-1.4-B01-top-hospitals" \
  --query-output-dir "省份报告/{province}/1.4_省级服务提供者总览/搜索结果/B_内部医院数据" \
  rank --by 客户名称 --metric IDA患者数 --top 20 --省 "{province}"

# B-02：省级总览（填充整体医院数和覆盖率摘要）
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-1.4-B02-summary" \
  --query-output-dir "省份报告/{province}/1.4_省级服务提供者总览/搜索结果/B_内部医院数据" \
  summary --省 "{province}"

# B-03：产品对比（填充每家医院的莫诺菲/科莫非流向）
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-1.4-B03-product-compare" \
  --query-output-dir "省份报告/{province}/1.4_省级服务提供者总览/搜索结果/B_内部医院数据" \
  product-compare --省 "{province}"
```

**说明**:
- B-01 `rank` 结果确定医院名单，同时提供每家医院的 IDA患者数、莫诺菲流向、科莫非流向，直接填入表格 `{internal_data_summary}` 列
- B-02 `summary` 提供全省覆盖率摘要，支撑 `{coverage_strategy_summary}`
- B-03 `product-compare` 补充双品对比，支撑 `{priority_city_or_hospital_cluster}` 判断

## 数据获取优先级约定

1. **第一优先** — CLI 内部数据（重点医院排名和流向数据）→ 填 `{internal_data_summary}`
2. **第二优先** — {省份}卫健委三甲医院名单、医院官网（学术地位、科室介绍）
3. **第三优先** — 医院排行榜（复旦排行榜、艾力彼医院排名）
4. **兜底** — 无内部数据时填"待内部数据补充"
