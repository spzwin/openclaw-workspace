## 模块D — 内部肾内科数据（CLI查询）

**来源类型**: `CLI查询`

**目标变量**: `{internal_data}`（本省重点医院肾内科"内部IDA患者数/流向"列）

**CLI命令**（串行执行）:

```bash
# D-01：按IDA患者数排名Top20
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-6.5-D01-top-hospitals" \
  --query-output-dir "省份报告/{province}/6.5_肾内科/搜索结果/D_内部肾内科数据" \
  rank --by 客户名称 --metric IDA患者数 --top 20 --省 "{province}"

# D-02：莫诺菲已覆盖医院（肾内科/透析场景）
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-6.5-D02-monof-covered" \
  --query-output-dir "省份报告/{province}/6.5_肾内科/搜索结果/D_内部肾内科数据" \
  detail --省 "{province}" --产品 "莫诺菲" --flow-status covered --sort-by IDA患者数 --desc --top 20
```
