# 检索指南 — 5.2 前10家重点医院逐院深度拆解

> 省份变量：`{省份}`（执行时由用户指定）
> **注**：重点医院名单须先通过 CLI 按 IDA患者数排名确定，再对各医院逐院搜索。

---

## 模块A — 重点医院名单确定（CLI查询）

**来源类型**: `CLI查询`

**目标变量**: `{top_hospital_1}` 等医院名称、`{internal_potential_and_flow}`（5.2.1详细表）, `{potential}`（5.2.2-10汇总表）

**CLI命令**（串行执行）:

```bash
# A-01：按IDA患者数排名Top10医院（确定重点医院名单）
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-5.2-A01-top10-hospitals" \
  --query-output-dir "省份报告/{province}/5.2_前10家重点医院逐院深度拆解/搜索结果/A_重点医院名单" \
  rank --by 客户名称 --metric IDA患者数 --top 10 --省 "{province}"

# A-02：对排名第1医院进行单院查询（获取详细数据）
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-5.2-A02-hospital1-detail" \
  --query-output-dir "省份报告/{province}/5.2_前10家重点医院逐院深度拆解/搜索结果/A_重点医院名单" \
  hospital --name "{top_hospital_1}" --fuzzy

# A-03：机会点分析（未覆盖高潜医院，辅助判断市场机会）
python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-5.2-A03-opp-monof" \
  --query-output-dir "省份报告/{province}/5.2_前10家重点医院逐院深度拆解/搜索结果/A_重点医院名单" \
  opportunity --type uncovered-high-potential --产品 "莫诺菲" --省 "{province}" --top 10

python pharma-province-report-skill/scripts/hospital_data.py \
  --excel "pharma-province-report-skill/references/hospital_base.xlsx" \
  --query-id "HDQ-{province_short}-5.2-A04-opp-kemofei" \
  --query-output-dir "省份报告/{province}/5.2_前10家重点医院逐院深度拆解/搜索结果/A_重点医院名单" \
  opportunity --type uncovered-high-potential --产品 "科莫非" --省 "{province}" --top 10
```

**说明**:
- A-01 `rank` 确定 Top10 医院名单（含每家的 IDA患者数、莫诺菲流向、科莫非流向），直接填入 `{internal_potential_and_flow}` 和 `{potential}`
- A-02 对排名第1医院做精确查询，填充 5.2.1 详细表格
- A-03/A-04 机会点数据支撑 `{hospital_market_opportunity}` 和 `{top_hospital_strategy}` 判断

## 模块B — 各重点医院公开资料（逐院搜索）

**来源类型**: `联网搜索`

> 在 CLI 确定医院名单后，对每家医院逐一执行以下检索：

| 目标变量 | 检索词模板 | 优先来源 |
|---|---|---|
| `{hospital_level}` | {医院名称} 级别 三甲 三级 | 医院官网 / {省份}卫健委 |
| `{city}` | {医院名称} 所在城市 地址 | 医院官网 |
| `{core_departments}` | {医院名称} 重点科室 血液科 消化科 肾内科 妇产科 | 医院官网 科室介绍 |
| `{academic_position}` | {医院名称} 学术地位 教学医院 国家重点学科 | 医院官网 / 医学媒体 |
| `{academic_events}` | {医院名称} 学术会议 主办 承办 2024 | 医院官网 / 医学会议资讯 |
| `{key_experts}` | {医院名称} 血液科 肾内科 消化科 主任 专家 教授 | 医院官网 专家介绍 |
| `{product_access_status}` | {医院名称} 药品 进院 静脉铁剂 | 公开采购信息 / 内部销售资料 |
| `{hospital_market_opportunity}` | 综合 CLI 数据 + 公开资料分析 | 综合判断 |

---

## 数据获取优先级约定

1. **第一优先** — CLI 内部数据（确定医院名单和流向，不可替代）
2. **第二优先** — 各医院官网（级别、科室、专家）
3. **第三优先** — {省份}卫健委三甲医院名单、复旦/艾力彼排行榜
4. **第四优先** — 医脉通、丁香园、健康界（专家信息）
5. **兜底** — 无公开资料时填"待内部销售团队补充"
