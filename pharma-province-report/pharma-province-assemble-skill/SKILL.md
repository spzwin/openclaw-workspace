# 省级报告拼装工作流

## 路径说明

所有路径均相对于 **workspace 根目录**（即 `skills/` 父级目录）。`省份报告/` 与 `skills/` 同级，不是与各 skill 子文件夹同级。

```
{workspace根目录}/
├── skills/
│   ├── pharma-province-report-skill/
│   └── pharma-province-assemble-skill/   ← 本 skill 所在位置
└── 省份报告/                              ← 读写此处（与 skills/ 同级）
```

## 输入

| 参数 | 说明 | 默认值 |
|---|---|---|
| **省份** | 目标省份，如 `广东省` | 必填 |
| **报告目录** | 各章节报告所在目录（相对项目根目录） | `省份报告/{省份}/` |

## 执行步骤

### Step 1 — 运行拼装脚本

```bash
python pharma-province-assemble-skill/scripts/assemble.py \
  --province "{省份}" \
  --report-dir "省份报告/{省份}"
```

脚本自动完成：
1. **章节完整性校验**：扫描目录，列出已生成和缺失的章节（共 20 个）
2. **拼装完整报告**：按章节顺序插入维度标题、分隔线，拼入各章 `报告.md` 内容
3. **生成目录**：在报告头部插入可跳转的 Markdown 目录
4. **添加参考文献**：报告末尾附各章节搜索结果目录链接
5. **写入输出文件**：`省份报告/{省份}/完整报告.md`

完成后输出：
```
✅ 完整报告已生成：省份报告/{省份}/完整报告.md（共 X/20 章节，Y 行）
```

### Step 2 — LLM 提取执行摘要（填充占位符）

脚本生成的完整报告执行摘要中有 3 个占位符需要填充：
- `{EXEC_IDA_BURDEN}` — 本省疾病负担
- `{EXEC_COMPETITION}` — 竞争格局
- `{EXEC_STRATEGY}` — 核心策略

按以下步骤提取并填充：

#### 2a. 读取 1.1 章节报告 → 提取疾病负担

读取 `省份报告/{省份}/1.1_全省流行病学与疾病负担/报告.md`，提取：
- `{省份}` IDA 患者池估算数字（万人）
- 估算依据（人口基数 + 流行病学参数 + 六科患者池来源）

填充格式：
```
{省份} IDA患者池估算约 **X 万人**；关键依据为 {人口基数说明}、{流行病学依据} 与 {六科患者池说明}。
```

#### 2b. 读取 3.1 章节报告 → 提取竞争格局

读取 `省份报告/{省份}/3.1_省级竞争格局/报告.md`，提取：
- 静脉铁剂市场竞争态势摘要（1–2 句）
- 莫诺菲和科莫非各自的准入/医保/临床定位优势（各 1 句）

填充格式：
```
{省份} 静脉铁剂市场呈现 {竞争态势}；莫诺菲与科莫非的准入、医保、临床定位和渠道优势分别为 {定位摘要}。
```

#### 2c. 读取 4.2 章节报告 → 提取核心策略

读取 `省份报告/{省份}/4.2_省级KOL分层管理/报告.md`，提取：
- 核心学术/渠道据点（省级医院或城市）
- 优先推进科室（2–3 个）
- 推广层级路径（省级→市级→县域）

填充格式：
```
建议以 {核心学术据点} 为学术与渠道据点，优先推进 {优先科室}，并围绕 {优先城市或医院层级} 建立分层覆盖路径。
```

#### 2d. 编辑完整报告替换占位符

用实际提取内容替换 `省份报告/{省份}/完整报告.md` 中的三处占位符：
- `{EXEC_IDA_BURDEN}` → 填入 2a 提取结果
- `{EXEC_COMPETITION}` → 填入 2b 提取结果
- `{EXEC_STRATEGY}` → 填入 2c 提取结果

完成后告知：`✅ 执行摘要已填充：省份报告/{省份}/完整报告.md`

---

### Step 3 — 确认并交付

- 打开 `省份报告/{省份}/完整报告.md` 检查目录是否完整、章节顺序是否正确、执行摘要内容是否准确
- 如有缺失章节，先用 `pharma-province-report-skill` 补齐，再重新运行脚本
