#### 当前标准治疗方案（IDA）

> 广西IDA治疗现状**[未找到]**专项调研，以下为全国常规治疗模式：

**口服铁剂（轻症首选）**
- 硫酸亚铁/琥珀酸亚铁/多糖铁复合物
- 胃肠道副作用率高（20-60%），依从性差
- 医保乙类（部分产品）

**静脉铁剂（中重度/口服无效/快速补铁）**
- **一代**：蔗糖铁（最多使用，但低磷血症风险高）
- **二代**：右旋糖酐铁（科莫非 — 基药+甲类医保，过敏试验必需）
- **三代**：异麦芽糖酐铁（莫诺菲 — 低磷血症8% vs 蔗糖铁75%，无需皮试，快速输注）

#### 患者流向

```
轻症IDA → 口服铁剂 → 基层/县级医院
     ↓（口服无效/不耐受）
中重度IDA → 静脉铁剂 → 市级/省级医院
     ↓（需快速补铁）
急诊/围术期 → 静脉铁剂（莫诺菲15-30min快速输注）→ 三甲
     ↓（CKD/透析）
肾内科/透析中心 → 静脉铁剂（莫诺菲可入透析机静脉端）
```
