# 莫诺菲 & 科莫非 省级市场报告系统

## 项目概述

本系统用于生成各省份的莫诺菲 / 科莫非产品市场分析报告，采用**章节独立执行 + 统一合并**的工作流：

1. **章节报告生成**（`pharma-province-report-skill`）：每个章节单独执行，联网搜索 + CLI 内部数据双数据源
2. **完整报告合并**（`pharma-province-assemble-skill`）：所有章节完成后，一键拼装成带目录和参考文献的完整报告

## 环境配置

### 安装依赖

```bash
pip install -r pharma-province-report-skill/requirements.txt
```

### 设置联网搜索 API Key

本系统联网搜索使用 **Tavily**：

```bash
export TAVILY_API_KEY=tvly-xxxxxxxxxxxxxxxxxxxxxxxx
```

> 建议写入 `~/.zshrc` 或 `~/.bashrc` 使其永久生效。

## 使用方法

### Step 1 — 生成单个章节报告

将以下 Prompt 复制给 Claude，**替换省份和章节路径**后发送：

```
目标省份：广东省
章节模版：统一省区报告模版拆分章节/1.1、全省流行病学与疾病负担/模版.md
检索指南：统一省区报告模版拆分章节/1.1、全省流行病学与疾病负担/检索指南.md

请使用 pharma-province-report-skill 开始执行章节报告工作流。
联网检索请使用 Tavily 搜索工具。
```

**输出位置**：`省份报告/广东省/1.1_全省流行病学与疾病负担/`
```
省份报告/广东省/1.1_全省流行病学与疾病负担/
├── 搜索结果/
│   ├── A_患者池/搜索结果.md
│   └── B_服务提供者/搜索结果.md
└── 报告.md   ← 最终章节报告
```

---

### Step 2 — 合并所有章节为完整报告

所有章节跑完后，将以下 Prompt 复制给 Claude：

```
目标省份：广东省

请使用 pharma-province-assemble-skill 合并完整报告。
```

或直接运行脚本：

```bash
python pharma-province-assemble-skill/scripts/assemble.py \
  --province "广东省" \
  --report-dir "省份报告/广东省"
```

**输出位置**：`省份报告/广东省/完整报告.md`

完整报告包含：
- 自动生成的三级目录（部分 → 维度 → 章节，含跳转锚链接）
- 三大部分 / 六个维度 / 20 个章节正文（按顺序拼装）
- 末尾参考文献列表（链接至各章节搜索结果目录）

## 注意事项

- **章节顺序无关**：各章节可按任意顺序执行，互不依赖
- **串行执行 CLI**：同一省份的多个含 CLI 章节，请不要同时开两个对话并发执行（同一 Excel 文件不支持并发读写）
- **重跑章节**：重跑某章节会覆盖该章节的 `搜索结果/` 和 `报告.md`，不影响其他章节
- **合并脚本可多次运行**：每次运行会覆盖 `完整报告.md`，以最新章节内容为准
- **缺失章节**：合并时若有章节缺失，脚本会跳过并在终端列出缺失清单，已有章节正常拼入
